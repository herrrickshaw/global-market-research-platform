💡 NOTES

Why Claude 3.5 Haiku?
  • 100% compatible with Claude 3 Haiku API
  • Cheaper per-token (same tier)
  • Faster inference (better for daily runs)
  • Better quality for structured output
  • No code changes needed (just model name)
  • Recommended by Anthropic as direct upgrade

What about optional upgrades (Sonnet)?
  • portfolio_analysis: Optional, after validation (Week 3)
  • put_call_parity: Optional, if trading volume high (Week 3)
  • Not deployed yet — waiting for Phase 1 results

Cache persistence:
  • _instrument_cache persists in memory during app lifetime
  • Auto-refreshes on app restart

  • Trades ~500KB memory for ~5% token savings
