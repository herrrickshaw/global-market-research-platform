## 🖨️ How to Create Additional PDFs

### On Mac (Recommended):

**For Markdown files (.md)**:
1. Open file in any text editor (TextEdit, VS Code, etc.)
2. Cmd+P (or File → Print)
3. In print dialog, click dropdown "PDF" (top-left)
4. Select "Save as PDF"
5. Choose filename and location

**For Text files (.txt)**:
1. Open file
2. Cmd+P
3. PDF dropdown → Save as PDF

**For CSV files (.csv)**:
1. Open in Excel or Numbers
2. File → Export As → PDF
