# Chemical Import Substitution: 8-Digit HSN Code Level Analysis
## Cross-Referenced with DCPC Annual Report Data

**Date**: August 2026  
**Source**: DCPC Annual Report (Directorate of Chemicals & Petrochemicals), Ministry of Chemicals & Petrochemicals, Govt. of India  
**Classification**: India's 8-digit tariff HSN codes (more granular than 6-digit HS)

---

## METHODOLOGY

**Why 8-digit HSN?**
- India's tariff classification uses 8-digit HSN codes (vs. international 6-digit HS codes)
- Allows separation of: virgin resin vs. recycled, technical grades vs. food-grade, etc.
- DCPC annual reports all chemicals at this level
- Enables precise substitution targeting (e.g., "food-grade acetic acid" vs. "industrial acetic acid")

**Data Integration**:
1. DCPC annual report imports/exports by 8-digit HSN code
2. TradeStat DGCIS corroboration (CY2024-25)
3. Government capex project mapping (BPCL AP, RIL O2C, etc.)
